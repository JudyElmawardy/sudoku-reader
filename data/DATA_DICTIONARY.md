# Data Dictionary

## Real Data (MNIST)

| Column / Field | Type | Description | Source |
|----------------|------|-------------|--------|
| image | float32 (28×28) | Greyscale handwritten digit, pixels scaled to [0,1] | MNIST |
| label | int (1-9) | True digit class. Digit 0 is dropped. | MNIST |
| split | str | "train", "val", or "test" | Generated split |

- Original MNIST: 60 000 train + 10 000 test images.
- We keep only digits 1-9.
- Train/Val split of original training set: 50 000 / 10 000 (fixed seed).
- Test set left untouched.

## Generated Data

### Sudoku Puzzles

| Field | Type | Description | Generation Rule |
|-------|------|-------------|-----------------|
| puzzle | int 9×9 | Grid with 0 = empty, 1-9 = given | Full grid generated by randomised backtracking; cells removed while uniqueness is preserved |
| solution | int 9×9 | Unique complete solution | Same backtracking run |
| n_givens | int | Number of non-zero cells | Controlled (e.g. 25, 30, 35) |
| seed | int | RNG seed used for this puzzle | User-supplied or sequential |

### Image Mosaics

| Field | Type | Description | Generation Rule |
|-------|------|-------------|-----------------|
| mosaic | float32 (252×252) | 9×9 grid of 28×28 digit images | Each non-empty cell is replaced by a real MNIST image of the required digit (or a hard/low-confidence image when injecting misreads) |
| true_grid | int 9×9 | The ground-truth digits used to build the mosaic | From the generated puzzle |
| injected_misreads | list of (r,c,true,wrong) | Cells where a wrong digit image was deliberately placed | Documented rule: select cells whose top-1 probability is below a threshold or force top-2 confusion |

### Correction / Search Log

| Field | Type | Description |
|-------|------|-------------|
| cell | (r,c) | Position corrected |
| read_digit | int | Digit predicted by NN |
| new_digit | int | Digit chosen by search |
| cost | float | Probability drop (never negative) |
| nodes_expanded | int | Search counter |
| nodes_generated | int | Search counter |

## Notes

- Blank cells are detected by a simple brightness threshold (mean pixel value below threshold), **not** by the neural network.
- All generated artefacts are reproducible from a single integer seed.
- Hard (low-confidence) test digits are injected according to a documented rule so that the network is not perfect and corrections become necessary.
